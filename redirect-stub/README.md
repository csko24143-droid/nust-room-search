# リダイレクト用スタブ

リポジトリを `nu-roomradar` Organization へ移管したあと、旧URL
`https://csko24143-droid.github.io/nust-room-search/`（掲示済みポスターのQRの飛び先）を
新LPへ転送し続けるためのページ。

## 使い方（移管後に1回だけ）

1. 旧アカウント `csko24143-droid` で新規リポジトリ `nust-room-search` を作成する
   （移管によって名前が空くので同名で作れる）。
2. この `index.html` だけをそのリポジトリのルートに置いてコミットする。
3. リポジトリの Settings → Pages で公開する（Deploy from a branch / main / root）。
4. 旧URLを開いて新LPへ転送されることを確認する。

掲示中のポスターをすべて新QR版に貼り替え終わったら、スタブのリポジトリごと削除してよい。
